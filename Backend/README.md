# Team12_WSI Backend

This is a JavaScript backend built with [Hono](https://hono.dev/) and running on [Bun](https://bun.sh/).

## Setup

1. Make sure you have Bun installed.
2. The project is already initialized and dependencies are installed.

## Running the server

To start the server in development mode (with hot reloading):

```bash
bun run dev
```

The server will be available at `http://10.21.131.115:3000` (for local network testing) or `http://localhost:3000` (for Mac browser).

## Project Structure

- `src/index.js`: The main entry point for the Hono application.
- `package.json`: Project configuration and scripts.
